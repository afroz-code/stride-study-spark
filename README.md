# 🚀 Smart Routine Management System  
### Student Productivity SaaS Web Application

A premium SaaS-style productivity web app designed to help students manage daily routines, track study sessions, monitor focus, and improve consistency.

🌐 Live Demo:
https://stride-study-spark.lovable.app

---

## 🎯 Key Features

- 🗓 Smart Daily Planner
- ⏳ Focus Mode (Study Session Tracker)
- 📊 Productivity Analytics Dashboard
- 🔥 Streak Tracking System
- 🎯 Weekly Goal Monitoring
- 🌙 Dark Mode Support
- 📩 Contact / Feedback System (Web3Forms API Integrated)
- 📈 Chart.js Performance Graphs
- 💾 LocalStorage Data Persistence
- 📱 Fully Responsive Design

---

## 🛠 Tech Stack

Frontend:
- React / Vite
- TypeScript
- Tailwind CSS
- shadcn/ui
- Chart.js

Other:
- Web3Forms API
- LocalStorage
- SaaS-inspired UI Design

---

## 💡 Project Objective

To build a structured productivity system that empowers students to:
- Improve time management
- Reduce distractions
- Maintain study consistency
- Track academic performance effectively
